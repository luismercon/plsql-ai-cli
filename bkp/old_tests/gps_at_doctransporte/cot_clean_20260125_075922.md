Procedure: gps_at_doctransporte

## General Description: 
This procedure is used to create a transportation document for an invoice. It retrieves customer and company information, validates the destination country, checks if the invoice has already been processed, and generates a transportation document with relevant details.

## Business Rules (SBVR format):

1. The procedure only processes invoices that have not been previously processed (status != 'PROCESSED').
2. The destination country for the transportation must be valid and supported ('PT' in this case).

## Logical Flow (procedural narrative):

- Retrieve customer information based on the provided seller code, mill code, invoice number, and invoice type.
- Validate if the customer has already been processed for the given load number.
- Check if the destination country is valid ('PT' in this case).
- Retrieve company information based on the seller code and mill code.
- Insert a new record into the 'gps_guiaremessa' table with relevant details such as customer information, document number, movement date, and other related data.
- Commit the transaction if it was started within the procedure.
