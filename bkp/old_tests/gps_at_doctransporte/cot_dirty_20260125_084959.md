Procedure: gps_at_doctransporte

## General Description: 
This procedure generates a transport document for overdue invoices, applying a surcharge for express orders and handling exceptions for credit limits.

## Business Rules (SBVR format):

1. The procedure only processes invoices that are overdue.
2. A surcharge is applied when the order type is 'EXPRESS'.
3. An exception is raised if the customer's credit limit is exceeded.

## Logical Flow (procedural narrative):

- Begin transaction
- Retrieve overdue invoices
- For each invoice, check order type and apply surcharge if necessary
- Check customer's credit limit
- If credit limit is not exceeded, generate transport document
- Commit transaction
