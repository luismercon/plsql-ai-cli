Procedure: gps_at_doctransporte

## General Description: 
This procedure is used to generate a delivery note (gps_guiaremessa) for a specified seller, mill, invoice number, and invoice type. It retrieves relevant data from various tables, performs checks, and inserts the new record if all conditions are met.

## Business Rules (SBVR format):

1. The procedure only processes invoices for the specified seller and mill.
2. The procedure only considers loads that have a corresponding shipping document.
3. The procedure inserts a new record into gps_guiaremessa if all conditions are met.

## Logical Flow (procedural narrative):

- The procedure starts by checking if a work transaction is already open. If not, it begins one.
- It then retrieves the load number for the specified seller, mill, invoice number, and invoice type from gps_shippingdoc.
- If no load number is found, an error message is returned and the procedure ends.
- The procedure retrieves various data points such as tax registration numbers, company names, addresses, cities, postal codes, countries, customer information, consignee information, warehouse information, and vehicle information from gps_shippingdoc, gps_customer, gps_consignee, gps_warehouse, and gps_vehicle.
- The procedure checks if the country code for the warehouse is 'PT'. If not, an error message is returned and the procedure ends.
- If all conditions are met, a new record is inserted into gps_guiaremessa with the retrieved data.
- Finally, the procedure commits the work transaction if it was started within the procedure.
