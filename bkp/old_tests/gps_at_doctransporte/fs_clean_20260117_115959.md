Procedure: gps_at_doctransporte

## General Description: 
This procedure is used to create a transport document for a given invoice number and type. It retrieves necessary data from various tables, performs validations, and inserts the data into gps_guiaremessa and gps_guiaremessa_lin tables.

## Business Rules (SBVR format):

1. Check if the invoice number and type exist in gps_ship_cmr table
2. Verify if the load number exists in gps_ship_plan table
3. Ensure that the customer code exists in gps_cust table
4. Confirm that the consignee code exists in gps_cons table
5. Validate that the products for the given invoice and type exist in gps_inv_item table
## Logical Flow (procedural narrative):

- Retrieve load number, customer code, and consignee code using invoice number and type from gps_ship_cmr table
- Fetch vehicle ID using load number from gps_ship_plan table
- Obtain company name, tax registration number, address details, and country using customer code from gps_cust table
- Insert data into gps_guiaremessa table
- Retrieve product details using invoice number and type from gps_inv_item table
- Insert product details into gps_guiaremessa_lin table
- Commit the transaction
