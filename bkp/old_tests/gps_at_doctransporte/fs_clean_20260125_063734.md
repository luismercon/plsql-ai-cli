Procedure: gps_at_doctransporte

## General Description: 
This procedure is used to generate a transportation document for a given seller code, mill code, invoice number, and invoice type. It checks if the invoice type is 'F' and if the load number exists in gps_ship_plan. If not, it raises an exception. It then retrieves customer information from gps_cust_mill and gps_cons_mill tables based on seller code, mill code, and consignee code. After that, it retrieves product information from gps_inv_item table based on seller code, mill code, invoice number, and invoice type. Finally, it inserts a new record into gps_guiaremessa and gps_guiaremessa_lin tables with the retrieved data.
