## General Description: 
This procedure generates a transport document for a given load number, customer code, and invoice number. It retrieves various data from different tables such as customer information, consignee information, shipment plan details, and CMR details. The procedure then inserts the retrieved data into the gps_guiaremessa table to create the transport document.

1. Checks if the load number exists and is not null
2. Validates the customer code
3. Verifies that the invoice number is not null or empty
