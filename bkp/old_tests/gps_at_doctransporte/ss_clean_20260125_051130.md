Procedure: gps_at_doctransporte

## General Description: 
This procedure generates a transportation document (guide) based on the provided invoice information. It retrieves relevant data from various tables, validates the input, and inserts the data into the 'gps_guiaremessa' table.

## Business Rules (SBVR format):

1. Checks if the invoice is from a valid seller and mill.
2. Validates the load number, customer code, and consignee code.
3. Verifies that the products exist for the given load number, customer code, and consignee code.
4. Ensures that the vehicle ID exists in the shipment plan for the given load number.

## Logical Flow (procedural narrative):

- Retrieves seller code, mill code, invoice number, and invoice type from the input arguments.
- Validates if the seller code is valid and retrieves the load number for the given invoice.
- Validates the customer code and consignee code based on the load number.
- Checks if products exist for the given load number, customer code, and consignee code.
- Retrieves vehicle ID from the shipment plan for the given load number.
- Inserts data into the 'gps_guiaremessa' table with the retrieved information.
