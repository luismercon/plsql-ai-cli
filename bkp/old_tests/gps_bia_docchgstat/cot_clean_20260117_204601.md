Procedure: gPS_BiA_DocChgStat

## General Description: 
This procedure updates the BiA status of a document and performs various checks and updates on related data. It handles exceptions for errors in updating Bia Period, updating BiA Invoice, and unable to update BiA Document.

## Business Rules (SBVR format):

1. The procedure does not execute if any argument is null or empty.
2. If the new BiA status is the same as the old one and it's an existing document, the procedure ends without making changes.
3. If the document type is 'NF' (Not Factored) and its net weight is 0, an exception is raised.
4. The procedure calls gPS_BiAUpdPeriod to update Bia Period with the item order, document weight, 'INV', '+', and user as arguments. If this call fails, an exception is raised.
## Logical Flow (procedural narrative):

- The procedure starts by checking if any argument is null or empty. If so, it raises an exception.
- It then retrieves data from the gps_bia_docs table based on the provided arguments.
- Depending on the document type ('NF' or not), it calculates the document weight and net value differently.
- If the new BiA status is the same as the old one and it's an existing document, the procedure ends without making changes.
- It calls gPS_BiAUpdPeriod to update Bia Period. If this call fails, an exception is raised.
- Depending on whether it's a new or existing document, it either updates the gps_bia_docs table or inserts a new record.
