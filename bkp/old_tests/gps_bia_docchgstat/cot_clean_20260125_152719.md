Procedure: gPS_BiA_DocChgStat

## General Description: 
This procedure is used to change the BiA status of a document. It takes several arguments including customer code, item order, seller code, mill code, document code, and document number. The procedure first validates the input arguments and then updates the BiA status in the gps_bia_docs table based on the new BiA status provided. If the update is successful, it calls the gPS_BiAUpdPeriod procedure to update the Bia Period for the order. The procedure also handles exceptions and rolls back any changes if an error occurs.

## Business Rules (SBVR format):

1. The procedure requires a valid customer code, item order, seller code, mill code, document code, and document number as input arguments.
2. The new BiA status must be different from the current BiA status of the document to update it.
3. If the document code is 'NF', the document weight must not be zero.

## Logical Flow (procedural narrative):

- Validate input arguments.
- Check if the new BiA status is different from the current BiA status of the document.
- If the document code is 'NF', check if the document weight is not zero.
- Call gPS_BiAUpdPeriod procedure to update the Bia Period for the order.
- Update the BiA status in the gps_bia_docs table based on the new BiA status provided.
- Handle exceptions and roll back any changes if an error occurs.
