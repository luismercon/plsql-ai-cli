Procedure: gPS_BiA_DocChgStat

## General Description: 
This procedure is used to change the BiA status of a document. It updates the BIA_DOCS table and calls the gPS_BiAUpdPeriod procedure to update the BIA period.

## Business Rules (SBVR format):

1. The procedure only updates documents that have a new BiA status different from the current one.
2. The procedure validates input parameters for null or empty values.
3. The procedure commits work at the end if it was started within the procedure.
4. The procedure handles exceptions and rolls back work in case of any errors.
## Logical Flow (procedural narrative):

- Start a new transaction.
- Validate input parameters for null or empty values.
- Check if the document exists in the BIA_DOCS table.
- Update the BIA_STATUS and MANUAL_STATUS columns of the BIA_DOCS table with the new BiA status.
- Call the gPS_BiAUpdPeriod procedure to update the BIA period.
- Commit work if it was started within the procedure.
