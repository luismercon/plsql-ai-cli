Procedure: gPS_BiA_DocChgStat

## General Description: 
This procedure updates the BIA_STATUS and MANUAL_STATUS of a document in gps_bia_docs if it exists, or inserts a new record into gps_bia_docs if it doesn't. It also calls the gPS_BiAUpdPeriod function to update the Bia Period for the order.

## Business Rules (SBVR format):

1. The procedure updates the BIA_STATUS and MANUAL_STATUS of a document in gps_bia_docs if lv_new_doc is equal to 0. If lv_new_doc is not equal to 0, it inserts a new record into gps_bia_docs.
2. The procedure calls the gPS_BiAUpdPeriod function with arguments av_item_ord, lv_doc_wgt, 'INV', '+', and av_user. If the returned lv_stat is less than or equal to 0, it raises an exception with a message indicating that it was unable to update the Bia Period for the order.
3. The procedure handles exceptions by setting lv_result to 0 and assigning an error message to lv_msg.

- Checks if lv_new_doc is equal to 0. If true, updates the BIA_STATUS and MANUAL_STATUS of a document in gps_bia_docs. If false, inserts a new record into gps_bia_docs.

- Handles exceptions by setting lv_result to 0 and assigning an error message to lv_msg.
