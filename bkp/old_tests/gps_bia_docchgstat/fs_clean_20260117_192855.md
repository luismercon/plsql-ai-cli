Procedure: gPS_BiA_DocChgStat

## General Description: 
This procedure is used to change the BiA status of a document. It updates the Bia Period, checks for changes in the BiA status and weight, and performs necessary updates or insertions into the gps_bia_docs table.

## Business Rules (SBVR format):

1. The procedure checks if the new BiA status is different from the old one before performing any updates.
2. If the document type is 'NF', it checks for a non-zero net weight before proceeding.
## Logical Flow (procedural narrative):

- Checks if the new BiA status is different from the old one.
- Calls gPS_BiAUpdPeriod to update the Bia Period.
- If the document already exists in gps_bia_docs, it updates the BiA status. Otherwise, it inserts a new record into the table.
