Procedure: gPS_BiA_DocChgStat

## General Description: 
Propose: This procedure is used to change the status of a document in the BiA system. It takes an argument and returns a result.

## Business Rules (SBVR format):

1. Checks if the new BiA status is different from the current one
2. Verifies if the document exists in gps_bia_docs
3. Ensures that the new BiA status is valid
4. Prevents changing the status of a document that has already been processed
## Logical Flow (procedural narrative):

- Initializes variables and checks for input errors
- Retrieves current BiA status from gps_bia_docs
- Compares new BiA status with the current one
- Verifies if the document exists in gps_bia_docs
- Checks if the new BiA status is valid
- Prevents changing the status of a processed document
- Updates or inserts the document into gps_bia_docs
- Commits changes and returns result
