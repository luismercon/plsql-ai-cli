Procedure: gPS_BiA_DocChgStat

## General Description: 
This procedure is used to change the BiA status of a document. It updates the Bia Period, checks for changes in BiA status and NetWgt, and handles insertion or updating of documents in the gps_bia_docs table.

## Business Rules (SBVR format):

1. Checks if the new BiA status is different from the old one
2. Verifies that the document has a NetWgt for invoices (cod_doc[1,2] = 'NF')

- Retrieves document and order information
- Updates Bia Period using gPS_BiAUpdPeriod procedure
- Checks for changes in BiA status and NetWgt
