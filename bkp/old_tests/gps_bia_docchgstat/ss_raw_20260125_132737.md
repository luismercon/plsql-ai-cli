Procedure: gPS_BiA_DocChgStat

## General Description: 
This procedure is used to change the status of a document in the BiA system. It takes various parameters such as customer code, item order, seller code, mill code, document code, and document number. The procedure first checks if the document already exists in the gps_bia_docs table. If it does, the procedure updates the bia_status and manual_status fields. If the document does not exist, a new record is inserted into the gps_bia_docs table.

## Business Rules (SBVR format):

1. Checks if the document already exists in gps_bia_docs. If it does, updates the bia_status and manual_status. If not, inserts a new record.
2. Validates input parameters for null or empty values.
3. Enforces business rules such as checking if the customer exists, if the order exists, and if the seller and mill exist.
4. Updates the gps_bia_period table with the document weight based on the invoice type.
5. Calls the gPS_BiAUpdPeriod procedure to update the BiA period.
