Procedure: gPS_BiAUpdPeriod

## General Description: 
This procedure is designed to update the BiA period for a specific customer. It takes into account various order types and their corresponding sales percentages, as well as reference days and tolerance days. The procedure also handles multiple currency handling.

## Business Rules (SBVR format):

1. A surcharge is applied only when ORDER_TYPE = 'EXPRESS'.
2. The procedure updates customers whose LAST_ACTIVITY_DATE is older than 90 days.
3. A new period is initialized if it does not exist for the given customer and period.

## Logical Flow (procedural narrative):

- The procedure starts by checking input parameters and initializing necessary variables.
- It then retrieves sales percentages, reference days, and tolerance days for the specified customer from the gps_customer_bia table.
- The procedure checks if a new period needs to be initialized for the given customer and period. If so, it inserts a new record into the gps_bia_period table with default values.
- Based on the order type (book or invoice), the corresponding sales columns are updated in the gps_bia_period table.
- Finally, the procedure commits the changes and returns a success message.
