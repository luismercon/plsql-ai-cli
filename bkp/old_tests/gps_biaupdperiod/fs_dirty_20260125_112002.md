Procedure: gPS_BiAUpdPeriod

## General Description: 
Propose: Update BiA Period for a Customer based on the provided arguments.

## Business Rules (SBVR format):

1. If the order destination is 'INDENT' or 'PRJIND', update indent_book_kgs or indent_inv_kgs. Otherwise, update stock_book_kgs or stock_inv_kgs.
2. If delivery policy matches '[FWL]', update direct_book_kgs or direct_inv_kgs. If it's 'T', update transit_book_kgs or transit_inv_kgs. If it's 'C', update calloff_book_kgs or calloff_inv_kgs.

## Logical Flow (procedural narrative):

- Validate input arguments.
- Determine the type of update (ORD or INV) and calculate corresponding quantities.
- Check if the BiA Period exists for the given Customer and Period. If not, initialize it with default values.
- Update the BiA Period with the calculated quantities.
- Return success message.
