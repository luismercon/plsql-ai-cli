Procedure: gPS_BiAUpdPeriod

## General Description: 
This procedure updates the BiA Period for a given customer and period based on the order details such as destination and delivery policy. It also handles inventory updates.

## Business Rules (SBVR format):

1. Check if the order destination is 'INDENT' or 'PRJIND'. If true, increment indent_book_kgs or indent_inv_kgs based on the function. Otherwise, increment stock_book_kgs or stock_inv_kgs. Check if delivery policy matches '[FWL]'. If true, increment direct_book_kgs or direct_inv_kgs. If false and delivery policy is 'T', increment transit_book_kgs or transit_inv_kgs. If false and delivery policy is 'C', increment calloff_book_kgs or calloff_inv_kgs.
2. Check if the period already exists in gps_bia_period. If not, insert a new record with initial values.

## Logical Flow (procedural narrative):

- Initialize variables to store incremental values for each type of booking and inventory.
- Determine which variables to increment based on the order destination and delivery policy.
- Check if the period already exists in gps_bia_period. If not, insert a new record with initial values.
- Update the corresponding fields in gps_bia_period with the calculated incremental values.
