Procedure: gPS_BiAUpdPeriod

## General Description: 
Propose: This procedure updates the BiA period for a given customer. It checks if it's a new period and initializes it if necessary. Then, it updates the period with the provided booked and invoiced quantities based on the order destination and delivery policy.

## Business Rules (SBVR format):

1. The procedure ensures that the BiA period is initialized if it doesn't exist for the given customer and period.
2. It enforces business rules related to order destinations and delivery policies when updating the period quantities.
## Logical Flow (procedural narrative):

- Check if the provided period exists for the customer.
- If not, initialize a new period with default values and customer-specific settings.
- Update the period with the provided booked and invoiced quantities based on the order destination and delivery policy.
